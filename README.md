# Namshi Product Scraper

A web scraper for **Namshi Saudi Arabia** that collects product information from the website.

## What Can It Do?

The scraper can collect:

* Product name
* Product price
* Rating
* Number of reviews
* Discount information
* Product link

The collected information can be saved as:

* CSV file
* JSON file

## How Can It Benefit You?

This scraper can help you:

* Collect many products quickly
* Save product information in one place
* Compare product prices
* Research products and competitors
* Analyze ratings and reviews
* Find discounted products
* Build product datasets
* Reduce the time spent collecting product information manually

## Example

You can use it to collect information about products such as:

* Nike shoes
* Adidas shoes
* Kids' products
* Clothing
* Sports products
* Other products available on Namshi

## Output

The collected information can be opened in:

* Microsoft Excel
* Google Sheets
* Other data analysis tools
